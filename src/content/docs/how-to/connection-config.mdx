Valkey GLIDE maintains consistent and intuitive configuration across all supported languages. 
This guides will go over how connection configurations are handled across clients and listing the available options.

## Configuration Patterns

GLIDE clients uses configuration `objects` to configure connections to Valkey. This keeps a consistent interface 
between clients while staying within the idiomatic norms of each specific programming language.

- **Node.js:** Uses dictionaries as `objects` with camelCase options.

- **Python:** Uses classes as config `objects` with snake_case named keyword.

- **Java:** Utilizes camelCase builder pattern to create configuration `objects`.

- **Go:** Employs a fluent interface with method chaining to create configuration `objects`.

For **standalone connections**, use [`GlideClientConfigurations`](#glideclientconfiguration) object. 

For **cluster connections**, use [`GlideClusterClientConfiguration`](#glideclusterclientconfiguration) object.

### Example

<Tabs>
    <TabItem label="Python">
    ```python
    from glide import GlideClientConfiguration, NodeAddress

    config = GlideClientConfiguration(
        addresses=[NodeAddress("localhost", 6379)],
        use_tls=True,
        request_timeout=1000,
        client_name="python_app"
    )
    ```
    </TabItem>

    <TabItem label="Node">

    ```typescript
    import { GlideClientOptions } from "@valkey/valkey-glide";

    const config: GlideClientOptions = {
        addresses: [{ host: "localhost", port: 6379 }],
        useTLS: true,
        requestTimeout: 1000,
        clientName: "node_app"
    };
    ```
    </TabItem>

    <TabItem label="Java">

    ```java
    import glide.api.models.configuration.GlideClientConfiguration;
    import glide.api.models.configuration.NodeAddress;

    GlideClientConfiguration config = GlideClientConfiguration.builder()
        .address(NodeAddress.builder().host("localhost").port(6379).build())
        .useTLS(true)
        .requestTimeout(1000)
        .clientName("java_app")
        .build();
    ```
    </TabItem>

    <TabItem label="Go">

    ```go
    import "github.com/valkey-io/valkey-glide/go/api"

    config := api.NewGlideClientConfiguration().
        WithAddress(&api.NodeAddress{Host: "localhost", Port: 6379}).
        WithUseTLS(true).
        WithRequestTimeout(1000).
        WithClientName("go_app")
    ```
    </TabItem>
</Tabs>

## Configuration Options
The following tables describe the available configuration `objects` and their options for GLIDE clients. 
To configure the client for each languages, follow the patterns described [above](#configuration-patterns).

:::note[Type Information]
The following data types aims to be generic between languages. For exact types, refers to the actual client's implementation. 
:::

### `GlideClientConfiguration` 

<Badge text="Type: Object" variant="note"/>

| Field Name                                               | Type                                                        | Description                                                                            | Default             |
| -------------------------------------------------------- | ----------------------------------------------------------- | -------------------------------------------------------------------------------------- | ------------------- |
| addresses                                                | List < [NodeAddress](#nodeaddress) >                        | A list of host and port pairs to connect to.                                           | Required            |
| use_tls                                                  | Boolean                                                     | Enables SSL/TLS encryption for the connection.                                         | false               |
| credentials                                              | [ServerCredentials](#servercredentials)                     | Authentication object containing username and password.                                | null                |
| database_id                                              | Integer                                                     | The logical database index to select (Standalone mode only).                           | 0                   |
| client_name                                              | String                                                      | A custom identifier for the client connection (visible in CLIENT LIST).                | null                |
| protocol                                                 | [Protocol \(Enum\)](#protocol)                              | The serialization protocol version (RESP2 or RESP3).                                   | RESP3               |
| read_from                                                | [ReadFrom \(Enum\)](#readfrom)                              | Routing preference for read operations (e.g., PRIMARY, PREFER_REPLICA, AZ_AFFINITY).   | PRIMARY             |
| client_az                                                | String                                                      | The Availability Zone the client is running in (Required if read_from is AZ_AFFINITY). | null                |
| request_timeout                                          | Integer                                                     | Maximum duration (in milliseconds) to wait for a request to complete.                  | Language Default    |
| reconnect_strategy                                       | [ReconnectStrategy](#reconnectstrategy)                     | Logic for retrying connections (backoff factor, retries, etc.).                        | Exponential Backoff |
| inflight_requests_limit                                  | Integer                                                     | Maximum number of concurrent requests allowed in the pipeline.                         | null (unlimited)    |
| advanced_config                                          | [AdvancedClientConfiguration](#advancedclientconfiguration) | Advanced configuration settings (TLS, connection timeout, etc.).                       | null                |
| pubsub_subscriptions                                     | [PubSubSubscriptions](#pubsubsubscriptions)                 | PubSub subscriptions to establish during connection.                                   | null                |
| lazy_connect                                             | Boolean                                                     | Defer connection establishment until the first command is sent.                        | false               |
| compression <Badge text="Python Only" variant="danger"/> | [CompressionConfiguration](#compressionconfiguration)       | Configuration for automatic compression of values.                                     | null                |

| protocol                                                 | [Protocol \(Enum\)](#protocol)                              | The serialization protocol version (RESP2 or RESP3).                                    | RESP3                   |
| read_from                                                | [ReadFrom \(Enum\)](#readfrom)                              | Routing preference for read operations (e.g., PRIMARY, PREFER_REPLICA, AZ_AFFINITY).    | PRIMARY                 |

### `ServerCredentials`
<Badge text="Type: Object" variant="note"/>

| Field Name | Type   | Description                                                                                       | Default   |
|------------|--------|---------------------------------------------------------------------------------------------------|-----------|
| username   | String | The user defined in the Redis/Valkey ACL.  (Leave null for legacy "password-only" authentication) | "default" |
| password   | String | The password associated with the user.                                                            | null      |

### `NodeAddress`
<Badge text="Type: Object" variant="note"/>

| Field Name | Type    | Description                               | Default  |
| ---------- | ------- | ----------------------------------------- | -------- |
| host       | String  | The hostname or IP address of the server. | Required |
| port       | Integer | The port number to connect to.            | Required |

### `Protocol`
<Badge text="Type: Enum" variant="caution"/>

| Value | Type | Description                                           |
| ----- | ---- | ----------------------------------------------------- |
| RESP2 | Enum | Redis Serialization Protocol version 2 (legacy).      |
| RESP3 | Enum | Redis Serialization Protocol version 3 (recommended). |

### `ReadFrom`
<Badge text="Type: Enum" variant="caution"/>

| Value                            | Type | Description                                                                                                |
| -------------------------------- | ---- | ---------------------------------------------------------------------------------------------------------- |
| PRIMARY                          | Enum | Route read operations to the primary/master node only.                                                     |
| PREFER_REPLICA                   | Enum | Route read operations to replica nodes when available, fallback to primary.                                |
| AZ_AFFINITY                      | Enum | Route read operations to replicas in the same availability zone as the client.                             |
| AZ_AFFINITY_REPLICAS_AND_PRIMARY | Enum | Route read operations within the client's AZ in round-robin manner (replicas → primary → fallback to any). |

### `ReconnectStrategy`
<Badge text="Type: Object" variant="note"/>

| Field Name        | Type    | Description                                       | Default |
| ----------------- | ------- | ------------------------------------------------- | ------- |
| number_of_retries | Integer | Maximum number of reconnection attempts.          | 3       |
| factor            | Float   | Multiplier for the backoff delay between retries. | 2.0     |
| exponent_base     | Integer | Base value for exponential backoff calculation.   | 2       |

### `CompressionConfiguration`
<Badge text="Type: Object" variant="note"/>

<Badge text="Python Only" variant="danger"/>

| Field Name           | Type                                      | Description                                                                                             | Default |
| -------------------- | ----------------------------------------- | ------------------------------------------------------------------------------------------------------- | ------- |
| enabled              | Boolean                                   | Whether compression is enabled.                                                                         | false   |
| backend              | [CompressionBackend](#compressionbackend) | The compression backend to use (ZSTD or LZ4).                                                           | ZSTD    |
| compression_level    | Integer                                   | The compression level to use. If not set, the backend's default level will be used.                     | null    |
| min_compression_size | Integer                                   | The minimum size in bytes for values to be compressed. Values smaller than this will not be compressed. | 64      |

### `CompressionBackend`
<Badge text="Type: Enum" variant="caution"/>

<Badge text="Python Only" variant="danger"/>

| Value | Type | Description                    |
|-------|------|--------------------------------|
| ZSTD  | Enum | Use zstd compression backend.  |
| LZ4   | Enum | Use lz4 compression backend.   |

### `PubSubSubscriptions`
<Badge text="Type: Object" variant="note"/>

| Field Name            | Type                                                            | Description                                    | Default  |
| --------------------- | --------------------------------------------------------------- | ---------------------------------------------- | -------- |
| channels_and_patterns | Map\<[PubSubChannelModes](#pubsubchannelmodes), Set\<String\>\> | Channels and patterns by subscription modes.   | Required |
| callback              | Function                                                        | Optional callback to accept incoming messages. | null     |
| context               | Any                                                             | Arbitrary context to pass to the callback.     | null     |

### `PubSubChannelModes`
<Badge text="Type: Enum" variant="caution"/>

| Value   | Type | Description                                              |
| ------- | ---- | -------------------------------------------------------- |
| Exact   | Enum | Use exact channel names for subscription.                |
| Pattern | Enum | Use channel name patterns for subscription.              |
| Sharded | Enum | Use sharded pubsub (Available since Valkey version 7.0). |

### `AdvancedClientConfiguration`
<Badge text="Type: Object" variant="note"/>

| Field Name         | Type                                                  | Description                                                                             | Default |
| ------------------ | ----------------------------------------------------- | --------------------------------------------------------------------------------------- | ------- |
| connection_timeout | Integer                                               | Duration in milliseconds to wait for a TCP/TLS connection to complete.                  | 2000    |
| tls_config         | [TlsAdvancedConfiguration](#tlsadvancedconfiguration) | Advanced TLS configuration settings for certificate validation and custom certificates. | null    |

### `TlsAdvancedConfiguration`
<Badge text="Type: Object" variant="note"/>

| Field Name       | Type    | Description                                                                      | Default |
| ---------------- | ------- | -------------------------------------------------------------------------------- | ------- |
| use_insecure_tls | Boolean | Whether to bypass TLS certificate verification (not recommended for production). | false   |
| root_pem_cacerts | Bytes   | Custom root certificate data for TLS connections in PEM format.                  | null    |

### `PeriodicChecksStatus`
<Badge text="Type: Enum | Object" variant="caution"/>

| Value                        | Type   | Description                                                 |
| ---------------------------- | ------ | ----------------------------------------------------------- |
| ENABLED_DEFAULT_CONFIGS      | Enum   | Enables periodic checks with default configurations.        |
| DISABLED                     | Enum   | Disables periodic topology checks.                          |
| PeriodicChecksManualInterval | Object | Custom interval configuration with `duration_in_sec` field. |

### `PeriodicChecksManualInterval`
<Badge text="Type: Object" variant="note"/>

| Field Name      | Type    | Description                                              | Default  |
| --------------- | ------- | -------------------------------------------------------- | -------- |
| duration_in_sec | Integer | Custom interval in seconds for periodic topology checks. | Required |
