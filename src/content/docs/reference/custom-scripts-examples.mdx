## Return Value Types

GLIDE automatically converts Lua return types to Python types:
- Lua strings → Python bytes (`b'...'`)
- Lua numbers → Python int
- Lua tables → Python lists
- Lua nil → Python None

```python
# Returns different types
script = Script("return {1, 2, 3, 'hello'}")
result = await client.invoke_script(script)
print(result)  # [1, 2, 3, b'hello']
```

## Inventory Management

Implement atomic stock deduction for a limited-edition product drop:

```python
inventory_script = Script("""
    local key = KEYS[1]
    local quantity_requested = tonumber(ARGV[1])
    
    local current_stock = tonumber(server.call('GET', key) or 0)

    if current_stock >= quantity_requested then
        server.call('DECRBY', key, quantity_requested)
        return 1 
    else
        return 0 
    end
""")

# Initialize stock
await client.set("product:shoe:stock", "100")

# Attempt purchase
result = await client.invoke_script(
    inventory_script,
    keys=["product:shoe:stock"],
    args=["3"]
)

if result == 1:
    print("✅ Purchase Successful!")
else:
    print("❌ Purchase Failed: Insufficient Stock.")
```

## Rate Limiting

Implement atomic rate limiting with automatic expiration:

```python
rate_limit_script = Script("""
    local key = KEYS[1]
    local limit = tonumber(ARGV[1])
    local window = tonumber(ARGV[2])

    local current = server.call('GET', key)
    if current == false then
        server.call('SET', key, 1)
        server.call('EXPIRE', key, window)
        return {1, limit}
    end

    current = tonumber(current)
    if current < limit then
        local new_val = server.call('INCR', key)
        return {new_val, limit}
    else
        local ttl = server.call('TTL', key)
        return {current, limit, ttl}
    end
""")

# Allow 10 requests per 60 seconds
result = await client.invoke_script(
    rate_limit_script,
    keys=["rate_limit:user:123"],
    args=["10", "60"]
)
```

## Conditional Update

Update a value only if it matches an expected state:

```python
conditional_update_script = Script("""
    local current = server.call('GET', KEYS[1])
    if current == ARGV[1] then
        server.call('SET', KEYS[1], ARGV[2])
        return 1
    else
        return 0
    end
""")

# Change status from "pending" to "active"
updated = await client.invoke_script(
    conditional_update_script,
    keys=["user:123:status"],
    args=["pending", "active"]
)

if updated:
    print("Status updated successfully")
else:
    print("Status was not 'pending', update skipped")
```

## Distributed Lock

Acquire and release locks atomically:

```python
acquire_lock_script = Script("""
    if server.call('SET', KEYS[1], ARGV[1], 'NX', 'EX', ARGV[2]) then
        return 1
    else
        return 0
    end
""")

release_lock_script = Script("""
    if server.call('GET', KEYS[1]) == ARGV[1] then
        return server.call('DEL', KEYS[1])
    else
        return 0
    end
""")

# Acquire lock with 30-second expiration
lock_acquired = await client.invoke_script(
    acquire_lock_script,
    keys=["lock:resource:123"],
    args=["unique_token", "30"]
)

if lock_acquired:
    try:
        # Perform work while holding lock
        pass
    finally:
        # Release lock
        await client.invoke_script(
            release_lock_script,
            keys=["lock:resource:123"],
            args=["unique_token"]
        )
```

## Troubleshooting

### CROSSSLOT errors in cluster mode
If you get a `CROSSSLOT` error, your keys are in different hash slots. Use hash tags to ensure they map to the same slot:

```python
# Fix: Use hash tags
keys=["user:{1000}:name", "user:{1000}:email"]
```

See the [concepts page](/revision-1/concepts/server-side-scripting/#the-crossslot-error) for details on how cluster routing works.


### Script timeout
If your script times out, use `script_kill()` to terminate read-only scripts. Scripts with write operations cannot be killed.

```python
await client.script_kill()
```

See [script termination](/revision-1/concepts/server-side-scripting/#script-termination-with-script_kill) for more details.

### Type conversion
Arguments are passed as strings. Convert them in your script:

```python
script = Script("""
    local limit = tonumber(ARGV[1])
    return limit + 10
""")
```
