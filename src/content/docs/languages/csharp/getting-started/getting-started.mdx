## System Requirements

The release of Valkey GLIDE was tested on the following platforms:

Linux:

* Ubuntu 24.04 (x86\_64/amd64 and arm64/aarch64)
* Amazon Linux latest (x86\_64)

<Aside>
  Currently Alpine Linux / MUSL is NOT supported.
</Aside>

macOS:

* macOS 15 (Apple silicon/aarch64)
* macOS 13 (x86\_64/amd64)

Windows:

* Windows Server 2025 (x86\_64/amd64)
* Windows 11 (arm64/aarch64)

## .NET Supported Versions

Valkey GLIDE C# supports .NET 8.0 and above.

## Installation and Setup

To install Valkey GLIDE in your C# project, follow these steps:

<Steps>
  1. Open your terminal in your project directory.
  2. Execute the command below:
     ```bash
     dotnet add package Valkey.Glide
     ```
  3. After installation, you can start up a Valkey server and run one of the examples in [Basic Examples](#basic-examples).
</Steps>

## Basic Examples

### Standalone Example

```csharp
using Valkey.Glide;
using static Valkey.Glide.ConnectionConfiguration;

var config = new StandaloneClientConfigurationBuilder()
    .WithAddress("localhost", 6379)
    .Build();

await using var client = await GlideClient.CreateClient(config);

var pong = await client.PingAsync();
Console.WriteLine(pong); // Round-trip time
```

### Cluster Example

```csharp
using Valkey.Glide;
using static Valkey.Glide.ConnectionConfiguration;

var config = new ClusterClientConfigurationBuilder()
    .WithAddress("localhost", 7001)
    .Build();

await using var client = await GlideClusterClient.CreateClient(config);

var pong = await client.PingAsync();
Console.WriteLine(pong); // Round-trip time
```

## Full Example with All Client Configurations

```csharp
using Valkey.Glide;
using static Valkey.Glide.ConnectionConfiguration;

// GlideClient example
var standaloneConfig = new StandaloneClientConfigurationBuilder()
    .WithAddress("primary.example.com", 6379)
    .WithClientName("some client name")
    .WithAuthentication("user1", "passwordA")
    .WithDataBaseId(1)
    .WithReadFrom(new ReadFrom(ReadFromStrategy.PreferReplica))
    .WithConnectionRetryStrategy(5, 10, 50)
    .WithRequestTimeout(TimeSpan.FromMilliseconds(500))
    .WithTls()
    .Build();

await using var standaloneClient = await GlideClient.CreateClient(standaloneConfig);

// GlideClusterClient example
var clusterConfig = new ClusterClientConfigurationBuilder()
    .WithAddress("address.example.com", 6379)
    .WithClientName("some client name")
    .WithAuthentication("user1", "passwordA")
    .WithReadFrom(new ReadFrom(ReadFromStrategy.PreferReplica))
    .WithRequestTimeout(TimeSpan.FromMilliseconds(500))
    .WithTls()
    .Build();

await using var clusterClient = await GlideClusterClient.CreateClient(clusterConfig);
```
