## Prerequisites

* [Task](https://taskfile.dev/) (recommended build tool)
* .NET 8 and 9
* Git
* GCC
* pkg-config
* cmake
* protoc (protobuf compiler) >= v3.20.0
* openssl
* openssl-dev
* rustup
* ziglang and zigbuild (for GNU Linux only)
* Valkey (for testing)
* WSL (for Windows only)

### Task Installation

[Task](https://taskfile.dev/) is a fast, cross-platform build tool. It is highly recommended to use `task` commands instead of raw `dotnet` commands for development.

## Build Instructions

{/*TODO csharp-docs: Is it necessary to include `dotnet` options at all?.*/}

<Steps>
  1. #### Install Common Prerequisites
     <InstallCommonPrereq />

  2. #### Clone the repository
     ```bash
     git clone https://github.com/valkey-io/valkey-glide-csharp.git
     cd valkey-glide-csharp
     ```

  3. #### Build the C# wrapper

     ```bash
     # Using Task (preferred):
     task build

     # Using dotnet:
     dotnet build
     ```

  4. #### Run tests

     ```bash
     # Using Task (preferred):
     task test

     # Run specific test suites:
     task test:unit         # Unit tests only
     task test:integration  # Integration tests only

     # Using dotnet:
     dotnet test -m:1
     ```
</Steps>

## Linting

Before making a contribution, run the code linters and analyzers:

```bash
# C# linter
dotnet format --verify-no-changes --verbosity diagnostic

# C# code analyzer
dotnet build --configuration Lint

# Rust linter
cargo clippy --all-features --all-targets -- -D warnings
cargo fmt --all -- --check
```
