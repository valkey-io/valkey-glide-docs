The Valkey GLIDE C# wrapper consists of both C# and Rust code. The Rust component exposes C-compatible functions via FFI, and the C# component calls them using [P/Invoke](https://learn.microsoft.com/en-us/dotnet/standard/native-interop/pinvoke) (`System.Runtime.InteropServices`). The C# wrapper translates the Rust async API into a .NET async API.
