As of Valkey 7.0, Valkey Function allows for custom Lua code to be executed on server-side similar to Lua [scripting](concepts/server-side-scripting.mdx).
GLIDE clients interface all support Valkey Functions. 

## Functions vs Scripts

Valkey Functions allows clients to create persistent Lua code for execution. It is not intended as a replacement for Lua scripting but rather a complementary feature.
Where as scripts are expected to be ephemeral and managed by the clients, Valkey Functions are persistent server-side 
functions that can be invoked by multiple clients.

```python
# lua code that updates a key and returns its new value
lua_code = """#!lua name=page_visits
server.register_function('update_visits', function(visits)
    server.call('INCR', visits[1])
    return server.call('GET', visits[1])
end)
"""

# loading the function to valkey
await client.function_load(lua_code, replace=True)

await client.set("page:home:visits", "0")

# calling the previously loaded function
result = await client.fcall("update_visits", keys=["page:home:visits"])

print(result)  # b'1'
```
