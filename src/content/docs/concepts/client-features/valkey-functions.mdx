As of Valkey 7.0, Valkey Function allows for custom Lua code to be executed on server-side similar to Lua [scripting](concepts/server-side-scripting.mdx).
GLIDE clients interface all support Valkey Functions. 

## Functions vs Scripts

Valkey Functions allows clients to create persistent Lua code for execution. It is not intended as a replacement for Lua scripting but rather a complementary feature.
Where as scripts are expected to be ephemeral and managed by the clients, Valkey Functions are persistent server-side 
functions that can be invoked by multiple clients.

### Example Lua Code

Lua functions are placed inside modules, registered through the `server.register_function` API.

```lua title="page_visits.lua"
#!lua name=page_visits
server.register_function('update_visits', function(visits)
    server.call('INCR', visits[1])
    return server.call('GET', visits[1])
end)
```

### Loading Custom Function
<Tabs syncKey="progLangInExamples">
<TabItem label="Python">
```python
# load the function from file
lua_code = open("page_visits.lua").read()
await client.function_load(lua_code, replace=True)

await client.set("page:home:visits", "0")

# call the loaded function
result = await client.fcall("update_visits", keys=["page:home:visits"])
print(result)  # b'1'
```
</TabItem>

<TabItem label="Java">
```java
// load the function from file
String luaCode = Files.readString(Path.of("page_visits.lua"));
client.functionLoad(luaCode, true).get();

client.set("page:home:visits", "0").get();

// call the loaded function
Object result = client.fcall("update_visits", new String[] {"page:home:visits"}, new String[0]).get();
System.out.println(result);  // "1"
```
</TabItem>

<TabItem label="Node">
```typescript
// load the function from file
const luaCode = fs.readFileSync("page_visits.lua", "utf8");
await client.functionLoad(luaCode, { replace: true });

await client.set("page:home:visits", "0");

// call the loaded function
const result = await client.fcall("update_visits", ["page:home:visits"], []);
console.log(result);  // "1"
```
</TabItem>

<TabItem label="Go">
```go
// load the function from file
luaCode, _ := os.ReadFile("page_visits.lua")
client.FunctionLoad(context.Background(), string(luaCode), true)

client.Set(context.Background(), "page:home:visits", "0")

// call the loaded function
result, _ := client.FCallWithKeysAndArgs(context.Background(), "update_visits", []string{"page:home:visits"}, []string{})
fmt.Println(result)  // "1"
```
</TabItem>
