# Contributing to Valkey GLIDE Documentation

Thank you for your interest in contributing to the [Valkey GLIDE documentation](https://glide.valkey.io)! This guide will go over how to contribute to our documentations.

> **Note:** This repository is for the documentation site only. To contribute to the Valkey GLIDE client library itself, see the [valkey-glide CONTRIBUTING guide](https://github.com/valkey-io/valkey-glide/).

## Prerequisites

Please ensure that you have set up the project according to our [Readme](/README.md).
